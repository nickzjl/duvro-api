THE LOOK
Cool, desaturated instant film, slightly muted rather than punchy, with heavy
grain — then composited onto a white instant-film frame with a markedly thicker
bottom border. NOTE the frame is a canvas composite, not an image edit: the
photo is placed on a white 4:5 card, never reshaped. If the provider cannot
produce the border reliably, generate the graded image only and let the app
composite the frame.

WHAT BASIC TIER DOES
The deterministic Core Image chain below is the same aesthetic, and premium
must read as that look executed better — not as a different look. These are
the app's own tuned values (duvro/Packs/digicam.json), hand-graded against
reference images. Op order is
temperatureTint -> colorControls -> vibrance -> toneCurve -> vignette ->
bloom -> grain. Baseline temperature is 6500K, so a lower number is warmer.

temperatureTint  temperature 7050, tint -16   (cool)
colorControls    saturation 0.93, brightness 0.0, contrast 1.0
vibrance         -0.03   (slightly muted, the only negative in this pack)
vignette         intensity 0.06, radius 1.5
bloom            radius 25.6, intensity 0.05
grain            intensity 0.24, size 1.0
polaroidFrame    borderWidth 0.07, bottom border 3.2x the sides
