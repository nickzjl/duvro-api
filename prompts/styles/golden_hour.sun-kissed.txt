THE LOOK
Warm late-afternoon daylight, and the most restrained of this pack's three.
Gently warmed, a touch of magenta, very slightly desaturated with a small
contrast lift. Barely any bloom or grain. This is the pack's signature look:
it is variants[0], so it is pre-selected on arrival and leads the showcase.

WHAT BASIC TIER DOES
The deterministic Core Image chain below is the same aesthetic, and premium
must read as that look executed better — not as a different look. These are
the app's own tuned values (duvro/Packs/golden_hour.json), hand-graded against
reference images. Op order is
temperatureTint -> colorControls -> vibrance -> toneCurve -> vignette ->
bloom -> grain. Baseline temperature is 6500K, so a lower number is warmer.

temperatureTint  temperature 5623, tint -16   (warm, slight magenta)
colorControls    saturation 0.96, brightness -0.0647, contrast 1.05
vibrance         0.07
vignette         intensity 0.10, radius 1.2
bloom            radius 16.6, intensity 0.04   (smallest bloom in the pack)
grain            intensity 0.024, size 1.3
