THE LOOK
Sun-bleached and aged. Heavily desaturated with muted vibrance, lifted blacks
so nothing reaches true black, the softest vignette falloff in the pack, and
heavy grain. Should read like a postcard left in a window for a decade — faded,
not dull or grey.

WHAT BASIC TIER DOES
The deterministic Core Image chain below is the same aesthetic, and premium
must read as that look executed better — not as a different look. These are
the app's own tuned values (duvro/Packs/travel_film.json), hand-graded against
reference images. Op order is
temperatureTint -> colorControls -> vibrance -> toneCurve -> vignette ->
bloom -> grain. Baseline temperature is 6500K, so a lower number is warmer.

temperatureTint  temperature 5752, tint -20
colorControls    saturation 0.79, brightness 0.0, contrast 1.0   (most desaturated in the app)
vibrance         -0.13   (muted further)
vignette         intensity 0.09, radius 1.6
bloom            radius 61.44, intensity 0.17
grain            intensity 0.23, size 1.3
