THE LOOK
Classic warm colour-negative film: warm, the most saturated variant in its
pack, with lifted vibrance and moderate grain. Rich and slightly nostalgic
without being faded — the opposite end of this pack from Faded Postcard.

WHAT BASIC TIER DOES
The deterministic Core Image chain below is the same aesthetic, and premium
must read as that look executed better — not as a different look. These are
the app's own tuned values (duvro/Packs/travel_film.json), hand-graded against
reference images. Op order is
temperatureTint -> colorControls -> vibrance -> toneCurve -> vignette ->
bloom -> grain. Baseline temperature is 6500K, so a lower number is warmer.

temperatureTint  temperature 5352, tint -20   (warmest in this pack)
colorControls    saturation 1.12, brightness 0.0, contrast 1.0
vibrance         0.20
vignette         intensity 0.07, radius 1.4
bloom            radius 47.36, intensity 0.15
grain            intensity 0.20, size 1.2
